Dextop WhatsApp Voice

This NVDA add-on optimizes the native voice recording quality in the WhatsApp Desktop app (modern version based on Microsoft WebView2).

What does this add-on do?

  • Disables aggressive audio filters: Deactivates Chromium's echo cancellation, noise suppression, and auto gain control (AGC), allowing you to record direct and clean microphone audio.
  • Forces High Quality (Opus 48kHz / 128kbps): Modifies WhatsApp's internal Opus compression parameters to studio quality, sending clean native voice notes (with their waveforms and playback speed controls).
  • Clean Uninstall & Shutdown: Reverts any registry modifications automatically when NVDA terminates, when the add-on is disabled, or when it is uninstalled from your system.

Requirements & Usage

  1. Install the add-on by double-clicking the .nvda-addon file and confirming NVDA restart.
  2. Close WhatsApp Desktop completely (make sure it's not running in the system tray) and reopen it. The add-on will automatically connect in the background.
  3. Record voice notes using the native microphone button in WhatsApp Desktop as usual.

Keyboard Shortcuts

Shortcut Description
NVDA+Shift+W Check add-on status (injection and connection status).
NVDA+Control+Shift+W Rewrite WebView2 registry configurations for WhatsApp Desktop.
NVDA+Alt+Shift+W Disable and clean all registry configurations applied to WhatsApp Desktop.

Security Advisory

This add-on enables a local debugging port on 127.0.0.1:59222 to communicate with WhatsApp Desktop via the Chromium protocol (WebView2) and inject the high-fidelity audio script.

  • No data is collected or sent to external servers in this version. All audio processing and settings manipulation remain local on your machine.
  • It is recommended to use this add-on only on trusted or personal computers. It is not recommended for public or shared environments.
  • Any registry changes are strictly temporary and will be cleared automatically whenever NVDA is closed, restarted, disabled, or uninstalled.
